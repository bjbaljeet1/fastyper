⌨️ FasTyper

FasTyper is a modern and responsive typing speed test application designed to help users improve their typing speed and accuracy. It provides real-time performance tracking, accuracy calculations, countdown timers, and an engaging user experience.

🚀 Features

- ⚡ Real-time typing speed (WPM) calculation
- 🎯 Live accuracy tracking
- ⏱️ Customizable countdown timer
- 🔄 Random text generation for practice
- 📊 Instant results and performance summary
- 🔊 Sound effects for better user interaction
- 📱 Responsive design for desktop and mobile devices
- 🌙 Clean and user-friendly interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
